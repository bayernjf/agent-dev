# Agent-Dev 外部 Pilot 招募

> 状态：招募中（v0.2 外部 Pilot）
> 日期：2026-08-28
> 目标：验证**非作者用户**能否独立完成一次真实产品交付
> 上游：[roadmap.md](./roadmap.md) v0.2 与 [implementation-plan-v0.2.md](./implementation-plan-v0.2.md) §7

## 我们在验证什么

Agent-Dev 是面向 AI 产品创作者的自主产品交付平台：你负责"产品为何存在"，Agent 负责"产品如何可靠地存在"。v0.1 已经由作者本人用三个真实项目连续跑通 Blueprint → Preview → 生产交付的完整闭环。v0.2 要回答一个 v0.1 没回答的问题：**不熟悉这个工具的开发者，能否不看作者讲解、独立完成首次交付？**

这不是一次功能试用，而是一次真实产品交付演练。你的完成率和反馈会直接决定 v0.2 后续功能取舍。

## 参与条件

- 使用 macOS，愿意安装 Node.js 22 并启动本地 Daemon（提供一键安装脚本）；
- 有一个**真实的待交付项目**——全新想法或已有仓库均可，但不是演示用 Demo；
- 愿意授权平台连接 GitHub 等账号（用于创建仓库、PR 和云端部署）；
- 能投入完成至少一次端到端交付，并填写反馈。

加分项：独立开发者或 2-5 人小团队；用过 Codex、Claude Code、Cursor 等 CLI 工具；有 GitHub 仓库或明确的产品想法。

## 你会获得什么

- Pilot 期内免费使用全部能力；
- 完整跑完两次交付并反馈的用户，可获更长试用期与书面致谢；
- 直接参与产品方向：你的反馈会决定 v0.2 是否纳入多 Profile 流水线等候选能力。

## 隐私与安全边界（不会做什么）

- Agent 在你的**本地机器**上运行，产物先落在本地隔离工作区，不读取/上传你的 Claude 登录 Token 等凭证；
- Secret 不进明文文件，平台只持有引用；Profile 等配置中的环境变量仅放行代理/区域白名单键；
- 任何远程资源创建（GitHub 仓库、Vercel/Cloudflare 部署、生产发布）都有人工审批闸门，Agent 不能自行触发。
- 详见 [SECURITY.md](../SECURITY.md)。

## 申请流程

1. 在仓库 Issue 页新建 Issue，选择 **Pilot 申请** 模板并填写；
2. 筛选通过后，我们会回复安装指引（一键脚本 + 诊断）；
3. 完成首次交付后，选择 **Pilot 反馈** 模板提交反馈；
4. 完成第二次交付后，填写退出问卷（含付费意愿，用于数据统计）。

## 反馈

任何阶段遇到问题，都用 **Pilot 反馈** 模板提 Issue（或直接通过 Feedback 通道提交）。请勿在 Issue 中粘贴 Secret、令牌或明文密钥。
